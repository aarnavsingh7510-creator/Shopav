# Hum Tum Aur Chai — Website Demo

A simple, responsive restaurant website built with plain HTML, CSS and JavaScript.

## Live site
This repository is intended to be connected to Vercel for automatic deployments.

## Edit the website
- Open `index.html` on GitHub.
- Click the pencil icon to edit.
- Change the text, menu items, sample prices, photos or contact details.
- Commit your changes to the `main` branch.
- Vercel will automatically build and publish the update.

## Important before using with customers
The menu names, prices and food photography are demo content. Confirm the actual menu, prices, hours and permission to use customer review excerpts before treating this as the restaurant's official website.
